# Your Task:
In your app.js file, practice using operators to solve a few small problems. Use console.log() to see your results.

## Requirements:

Arithmetic: Create variables total and items. Calculate the average and log the result.

Comparison: Create two variables, password and confirmPassword. Use a strict equality operator to check if they are the same and log the boolean result.

Logical: Create two boolean variables, hasTicket and isGuest. Create a variable canEnter that is true if either hasTicket OR isGuest is true. Log the value of canEnter.
Validation: Create a variable age. Write an expression that checks if age is greater than or equal to 18. Log the result.
